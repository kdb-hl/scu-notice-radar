# 川大校园通知雷达（scu-notice-radar）

盯住四川大学**教务处 / 学工部 / 学校主站 / 各学院**的通知公告，抓回条目后和上次记录比对，**只提醒新增**，并按关键词自动高亮。

两个版本，同一个数据内核：

| 版本 | 入口 | 适合谁 |
| --- | --- | --- |
| **桌面应用** | `dist\川大通知雷达.exe` | 日常用：看板式界面，每个来源一个分格、按权重排大小，点格子看列表 |
| 命令行 | `python radar.py check` | 接定时任务、自动推送 |

纯 Python 标准库，零依赖（Python 3.8+，Windows / macOS / Linux 都能跑）；桌面版已打包成单个 exe，无需安装 Python。

**位置**：`dist\川大通知雷达.exe`（13 MB，双击运行，免安装）

界面是「看板」：每个来源一个分格，**格子大小 = 权重**，紫色描边表示有新增；点格子进入该来源的列表。

```
┌─ 川大通知雷达 ───────────── 检索：[ 推免 ] [立即刷新] [导出] ────┐
│ 总通知 295 | 新增 0 | 命中关键词 104 | 来源 21 | 最后刷新 12:26 │
│ [全部][教务处][学工部][学校][学院] [只看新增][★命中关键词] 排序 │
├─────────────┬─────────────┬──────────────────────────────────────┤
│ 水利水电学院 │ 教务处·通知  │ 学工部·通知公告                      │ ← 4 列大格
│ 20 条 ★重点  │ 11 条 ★重点  │ 6 条 ★重点   条数 + 近12周趋势 + 标题 │
├───────┬───────┬───────┬───────┴─────┬─────────────┬───────────────┤
│生命科学│化学学院│川大主站│人工智能学院│物理 公共管理 │ 华西药 体育    │ ← 3 列中格
├────┬────┬────┬────┬────┬───────┴───────┬───────┬───────────────┤
│材料 │化工 │网安 │基医 │碳中和│ 卓越工程师     │ … 可滚动 …         │ ← 2 列小格
└────┴────┴────┴────┴────┴────────────────┴───────┴───────────────┘
```

**权重公式**（决定格子大小）：

`权重 = 来源优先级×3 + 近 30 天条数×0.8 + 关键词命中×0.6 + 未读×2`

- 优先级默认：教务处 / 学工部 / 学校主站 / 水利水电学院 = 3（★ 重点），其余 = 1；
- 分档：权重最高的 3 个 → 4 列大格，接着 4 个 → 3×2 大格，再 8 个 → 3 列中格，其余 2 列小格；
- 有新增的格子：紫色描边 + 「+n 新」角标。

**改权重不用改代码**：编辑 `data\config.json` 里的 `weights`：

```json
"weights": {
  "priority": { "教务处·通知公告": 3, "学工部·通知公告": 3, "水利水电学院": 3 },
  "default_priority": 1,
  "formula": { "priority": 3, "recent30": 0.8, "hits": 0.6, "unread": 2.0 },
  "tiers": { "hero": 3, "large": 4, "mid": 8 }
}
```

把你最关心的来源在 `priority` 里调大（比如自己学院填 5），格子就会更大；改完保存，回程序点「立即刷新」。

**操作**：

- 点格子 → 该来源的通知列表（二级页）；点一条 → 浏览器打开并自动标记已读；
- **看板/列表里按住鼠标或手指上下拖动 = 滑动页面**（触摸屏单指拖动即可，甩一下有惯性）；
- **键盘也能滚**（不依赖触摸手势的兜底）：↑↓ 小步、PgUp/PgDn（或空格）翻页、Home/End 回顶/到底；在搜索框里打字时不会抢键；
- 列表里右键：复制标题 / 复制链接 / 标记已读、未读；右上角「只看未读」「打开最新」；
- 顶部检索框输入即搜（空格 = 多个词都要含，`-词` = 排除）；可筛「只看新增 / ★ 命中关键词」；
- 排序可切「权重优先 / 条数优先 / 最新优先」；按 Esc 或「← 返回看板」回到总览；
- **鼠标滚轮在界面任意位置都能滚**（顶栏、统计条、筛选条、状态栏上方都行）；右侧进度条可以直接拖；
- **按住周边装饰区拖动即可移动窗口**（顶栏、统计条、筛选条、状态栏）；窗口位置会自动记住（跑到屏幕外会自动拉回）；
- 「视图 → 自动刷新」可让软件每 15/30/60/120 分钟自己抓一次；
- 某个来源抓取失败时，会**沿用该来源上次的通知**而不是清空，状态栏会提示「N 个站点失败」；
- 断网也能看：显示上次抓取的缓存。
- 重复双击程序不会开出第二个窗口，而是把已经在跑的那扇窗口顶到前面（避免两个窗口各写各的数据）。

## 二、命令行版

盯住四川大学**教务处 / 学工部 / 学校主站 / 你所在学院**的通知公告列表页，抓回条目后和上次记录比对，**只提醒新增**，并按关键词自动高亮。

为什么值得装：保研（推免）、奖学金、大创、竞赛报名、补退选、四六级这类通知，**错过一天可能就错过一年**。靠人天天刷四个网站是不现实的。

纯 Python 标准库，零依赖（Python 3.8+，Windows / macOS / Linux 都能跑）。

## 一句话用法

```bash
cd scu-notice-radar
python radar.py check
```

- **首次运行**会自动"建基线"：把现有通知全部记为已读，不会刷屏。
- 之后每次运行只输出**新增**通知；命中"重点关键词"的会打 ★ 并单列。
- 每次运行都会生成摘要：`digest/latest.html`（也就是 `digest/最新.html`，浏览器打开看）+ `digest/最新.md`；同时留一份带时间戳的存档。

Windows 上双击 `一键检查.bat` 也能跑（跑完自动打开摘要页）。

## 命令清单

| 命令 | 作用 |
| --- | --- |
| `check` | 检查新增（日常就这一条） |
| `check --json` | 输出 JSON，给定时任务 / 机器人推送用 |
| `check --all` | 不看已读状态，列出当前所有通知（第一次想通览时用） |
| `check --keywords-only` | 只报告命中关键词的通知 |
| `check --site 学工部` | 只检查某个站点 |
| `check --days 7` | 只看最近 7 天的通知（默认 45，`0` = 不限） |
| `list --limit 8` | 列出最近通知，不写状态（纯浏览） |
| `test <网址>` | 验证一个新站点能不能抓、能抓到什么（加站点前必做） |
| `sites` | 查看站点与开关状态 |
| `sites --add 名称=网址` | 添加站点 |
| `sites --disable 学工部` | 停用站点 |
| `keywords` | 查看关键词 |
| `keywords --add 暑期学校,夏令营` | 加关键词（逗号分隔） |
| `keywords --hot 推免,奖学金` | 把关键词设为"重点"（命中打 ★） |

## 加站点 / 改关键词

站点、关键词**全在 `data\config.json`（桌面版）或 `sites.json`（命令行版）** 里，不用改代码：

```jsonc
{
  "keywords": ["推免", "奖学金", "竞赛", "报名", "..."],
  "hot_keywords": ["推免", "夏令营", "奖学金", "..."],
  "sites": [
    {
      "name": "计算机学院",
      "category": "学院",          // 教务处 / 学工部 / 学校 / 学院
      "url": "https://cs.scu.edu.cn/tzgg.htm",
      "enabled": true,
      "note": "自建"
    }
  ]
}
```

加站点前先验证：

```bash
python radar.py test https://cs.scu.edu.cn/tzgg.htm
```

- 能列出条目 → 直接 `python radar.py sites --add 电气学院=https://ee.scu.edu.cn/tzgg.htm`。
- 列不出来 → 说明该页是 JS 渲染的，脚本抓不到静态列表（表现是页面能打开但"没有解析到条目"）。
- 返回 412/403 → 站点有反爬，需要浏览器访问。

## 配合定时任务自动提醒

`radar.py check --json` 输出结构化结果（新增条数、命中关键词、标题、链接、摘要），可以直接接到定时任务里，每天早晚各跑一次并把结果推给你。

例如（EasyClaw 环境）：

```bash
easyclaw cron add --name "校园通知雷达" --session isolated --cron "0 8,20 * * *" \
  --message "运行 python <项目路径>/radar.py check --json，若有新增通知就汇总成简短列表发给我（无新增则不用打扰）"
```

（不同环境命令不同，核心是：定时执行 `radar.py check --json`，再决定要不要推送。）

## 实现要点（给想改代码的人）

- 解析不依赖第三方库：按 `<li>` 切块，从块里取 `<a href>`、标题（`title` 属性 → `<h3>` → `<p class="title">` → `<div class="text">` → 链接文字）、日期、摘要。
- 日期归一化处理了川大在用的 4 种写法：`2026-09-14`、`09/20 + 2026`、`21 + 2026-09`、`03 + 2026.07`，并优先从 `<div class="date">` 区域取日期，避免标题里的 `2026-2027学年` 干扰。
- 已读状态存 `state.json`，按**文章 URL** 判重（川大 CMS 的文章地址是稳定的），每个站点最多保留 1000 条。
- 站点任一条抓取失败不会影响其他站点，失败信息会汇总进摘要。
